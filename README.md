# Landing Page Coraline

Landing page inspirada no universo visual de *Coraline*, desenvolvida como um projeto de Front-End com foco em composição visual, organização de conteúdo e apresentação de personagens.

> Projeto não oficial, criado para fins de estudo e prática em desenvolvimento web.

## Demonstração

Acesse a versão online do projeto:

[Visualizar Landing Page Coraline](https://landing-page-coraline-xpch.vercel.app/ )

## Sobre o projeto

A proposta desta landing page é criar uma experiência visual inspirada na atmosfera misteriosa e fantástica de *Coraline*, apresentando informações sobre a personagem principal e outros personagens do universo da obra.

O projeto foi desenvolvido para praticar:

- Estruturação de páginas com HTML;
- Criação de estilos com CSS e Sass;
- Organização de arquivos de Front-End;
- Uso do Gulp para automação de tarefas;
- Construção de uma interface visual temática;
- Desenvolvimento de uma página adaptável a diferentes tamanhos de tela.

## Como executar o projeto localmente

### Pré-requisitos

Antes de começar, você precisa ter instalado:

- [Node.js](https://nodejs.org/)
- NPM, que normalmente é instalado junto com o Node.js

### Instalação

Clone este repositório:

```bash
git clone https://github.com/Marcela-prog/landing_page_coraline.git
```

Entre na pasta do projeto:

```bash
cd landing_page_coraline
```

Instale as dependências:

```bash
npm install
```

### Executando o projeto

Para acompanhar as alterações durante o desenvolvimento:

```bash
npm run dev
```

Para compilar os arquivos Sass:

```bash
npm run build
```

Depois, abra o arquivo `index.html` no navegador.

## Organização do desenvolvimento

Os arquivos de origem ficam dentro da pasta `src`. Durante o desenvolvimento, o Gulp é utilizado para compilar os arquivos Sass e copiar os arquivos JavaScript para a pasta `dist`.

- `src/scss/`: arquivos de estilo escritos em Sass;
- `src/js/`: arquivos JavaScript de origem;
- `dist/css/`: arquivos CSS compilados;
- `dist/js/`: arquivos JavaScript preparados para uso;
- `gulpfile.js`: configuração das tarefas automatizadas.
